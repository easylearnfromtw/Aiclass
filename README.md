# SIGNWELL AI CLASS

**Learn. Build. Prove.**

SIGNWELL AI Education Group 的第一階段公開概念網站。以 AI 教育、實作型評量、學習追蹤為核心，設計可擴展至多學院、企業培訓與技能認證的平台。

## 查看網站

- GitHub: https://github.com/easylearnfromtw/Aiclass
- GitHub Pages 啟用後：https://easylearnfromtw.github.io/Aiclass/

### 啟用 GitHub Pages

在儲存庫選擇 **Settings → Pages → Build and deployment → Deploy from a branch**，選擇 **main** 與 **/(root)**，然後按 **Save**。當 GitHub 頁面顯示成功部署後，使用上方 Pages 網址。此步驟需由儲存庫管理員在 GitHub 設定中完成。

## 重要限制

本版是 **純前端 proof of concept**，使用瀏覽器 localStorage 保存體驗記錄。講義工作台沒有登入或角色權限，任何訪客都可以操作本機版本，但修改不會寫回 GitHub 或發布給其他訪客。清除瀏覽器資料、更換瀏覽器或裝置後，資料無法同步。

**未實作**：正式講義雲端儲存／PDF 檔案上傳／教師審核及同步發布、正式帳號登入、跨裝置同步、課程影片服務、可證明身份的正式考試、評分審核與申訴、有效的證書核發／撤銷／查驗、社群資料庫、真正的預約媒合、金流、電子發票、訂閱、推薦歸因或佣金發放。

網站所有成績、教材、樣板證書及後台數字均不代表真實營運成果。**請勿輸入個資或敏感業務資料**。

## 結構

- index.html — HTML 骨架與 SEO 資訊
- styles.css — 完整響應式設計系統
- app.js — 前端路由、課程、測驗及本機示範功能
- handouts.js — 講義庫、Markdown 閱讀器、筆記／收藏與本機教材工作台
- handouts.css — 講義系統專用樣式與列印版型
- polish.css — v1.2 全站視覺細節與閱讀 UI 優化
- ui.js — 閱讀進度、章節導覽、字級與專注模式（純前端增強）
- favicon.svg — 品牌圖示
- .github/workflows/check.yml — JavaScript 語法與網站檔案檢查

此版為無建置需求的靜態網站，直接開啟 index.html 或使用 GitHub Pages 部署；內部使用 hash-based routing，因此支援在 GitHub Pages 專案子路徑下瀏覽。

## 講義系統使用方式

1. 開啟網站的「課程講義」，可搜尋標題、摘要及講義內文，或按課程篩選。
2. 在講義頁面可收藏、標記已讀，以及在本機儲存私人筆記；文字講義可以列印或透過瀏覽器另存 PDF。
3. 講義閱讀頁可切換字級、使用桌面版側邊目錄或閱讀專注模式。調整保存在此裝置。
4. 在「講義編輯工作台」建立或修改文字講義，也能新增 HTTPS 外部 PDF 連結。編輯的資料只存在目前瀏覽器，重新安裝或清除網站資料將遺失。
5. 公開付費教材、教師專屬後台和真正的 PDF 雲端上傳，需要正式身分驗證和伺服器儲存，不能只依賴 GitHub Pages。
